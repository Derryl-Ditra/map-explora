# ASD-STE100 Controlled English Rule

Apply the ASD-STE100 (Simplified Technical English) specification to all technical documentation, explanations, and instructions:

1. **Sentence Length**:
   - Procedural sentences (instructions): Maximum 20 words.
   - Descriptive sentences: Maximum 25 words.
2. **Clarity & Voice**:
   - Give only one instruction per sentence.
   - Use imperative mood for instructions ("Remove the bracket.", "Turn the switch.").
   - Use active voice for descriptive text.
3. **Controlled Vocabulary**:
   - Use approved words only (e.g., *make sure*, *start*, *use*, *stop*).
   - Do not use contractions (*don't*, *can't*, *it's* are prohibited).
   - Do not use progressive `-ing` forms or perfect tenses.
   - Only use approved modals: *must* (mandatory), *can* (ability/possibility), *may* (permission). Do not use *shall* or *should*.
4. **Noun Strings**:
   - Maximum 3 consecutive nouns in any noun phrase.
