# ASD-STE100 Controlled Vocabulary Guide

ASD-STE100 enforces a controlled dictionary where each approved word has **one meaning** and **one approved part of speech**.

---

## 1. High-Frequency Forbidden Words & Approved Substitutions

| Unapproved Word | Approved STE Replacement | Example / Usage Note |
| :--- | :--- | :--- |
| **allow / permit** | **let** | "Let the adhesive dry." |
| **approximate / roughly** | **about** | "Wait for about 5 minutes." |
| **as well as** | **and** | Keep conjunctions clear and simple. |
| **assure / ensure / verify** | **make sure** | "Make sure that the indicator is green." |
| **begin / commence / initiate** | **start** | "Start the engine." |
| **by means of** | **with** / **by** | "Clean the surface with a cloth." |
| **check** (v.) | **examine** / **inspect** / **measure** | "Check" is only approved as a specific test procedure noun. Use *examine* for visual, *measure* for quantitative. |
| **depict / display / indicate** | **show** | "The display shows an error code." |
| **due to / owing to** | **because of** | "The pump stopped because of low oil pressure." |
| **employ / utilize** | **use** | "Use the approved torque wrench." |
| **fasten / secure** | **attach** / **tighten** | Use precise actions: *attach the bracket*, *tighten the bolts*. |
| **in order to** | **to** | Eliminate filler phrases. |
| **modify / alter** | **change** | "Do not change the factory settings." |
| **monitor** (v.) | **observe** | "Observe the pressure gauge during operation." |
| **obtain** | **get** | "Get a new gasket from inventory." |
| **perform / carry out** | **do** | "Do the calibration procedure." |
| **prior to / before** | **before** | "Before you start the test..." |
| **provide** | **give** / **supply** | "This manual gives instructions..." |
| **terminate / abort / halt** | **stop** | "Stop the pump immediately." |
| **utilization** | **use** (n.) | Avoid nominalizations. |
| **via** | **through** / **with** | "The fluid flows through the conduit." |

## 2. Common Part of Speech Pitfalls

In ASD-STE100, words are approved **only** for specific grammatical categories:

- **CLOSE**:
  - *Approved*: Verb only ("Close the door.").
  - *Unapproved*: Adjective or Adverb. For proximity, you must use **near** ("Keep the tool near the workstation", NOT "close to the workstation").
- **DAMAGE**:
  - *Approved*: Noun only ("Examine the pipe for damage.").
  - *Unapproved*: Verb. Do not say "This will damage the cable". Say: "This can cause damage to the cable."
- **OIL**:
  - *Approved*: Noun only ("Add oil to the tank.").
  - *Unapproved*: Verb. Do not say "Oil the hinges". Say: "Apply oil to the hinges."
- **LIGHT**:
  - *Approved*: Noun ("The warning light flashes.") or Adjective for weight/color.
  - *Unapproved*: Verb. Do not say "Light the torch". Say: "Ignite the torch."
- **DISCONNECT**:
  - *Approved*: Verb only ("Disconnect the plug.").
  - *Unapproved*: Noun. Do not say "During the disconnect...". Say: "When you disconnect...".

## 3. Standard Numbers, Ranges, and Units

- Always use digits for quantities in technical specifications (*2 mm*, *5 bolts*, *10 minutes*).
- Use hyphenated expressions for compounds acting as modifiers (*a 10-mm bolt*, *a 2-hour duration*).
- Express ranges explicitly:
  - *Approved*: "From 15°C to 25°C" or "Between 15°C and 25°C".
  - *Unapproved*: "15-25°C" or "15 to 25 deg C".
- Always write out percentages: use `%` with a preceding digit (*5%*).

---

## 4. Controlled Connectors and Conjunctions

- Use **and** to connect equal items or parallel simple clauses.
- Use **or** for alternatives. Do not use *and/or*.
- Use **but** for contrast.
- Use **because** (conjunction) or **because of** (preposition) for causes. Avoid *since* or *as* to denote causality.
- Use **then** to show chronological sequence (*"Remove the nut. Then remove the bolt."*).
