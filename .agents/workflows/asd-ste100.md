# ASD-STE100 (Simplified Technical English)

Please apply the ASD-STE100 specification to the following task or document:

## Core Requirements
1. **Procedural sentences (instructions)**: Maximum 20 words, imperative mood, only one instruction per sentence.
2. **Descriptive sentences**: Maximum 25 words, active voice.
3. **Controlled vocabulary**: Use only approved words (e.g., *make sure*, *start*, *use*, *stop*). Do not use contractions or progressive `-ing` verb forms.
4. **Noun clusters**: Maximum 3 consecutive nouns.
5. **Safety alerts**: Strict sequence (WARNING for injury/death, CAUTION for equipment damage, NOTE for non-imperative context).
