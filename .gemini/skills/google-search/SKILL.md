# Skill: Google Search MCP (Live Intelligence)
Source: google/mcp-google-search

## Purpose
Enables real-time web access for documentation, security alerts, and market intelligence. Ensures architectural decisions are based on the latest available data.

## Core Instructions
1. **Live Verification**: Always check the latest status of a library or API before implementation.
2. **Security Monitoring**: Proactively search for recent vulnerability reports related to the project stack.
3. **Market Intelligence**: Use live search to refine product features based on real-time market needs (e.g., Jakarta EV trends).
4. **Context Enrichment**: Supplement the internal knowledge base with up-to-date documentation and best practices.

## MCP Configuration
- Command: `npx`
- Args: `["-y", "@modelcontextprotocol/server-google-search"]`
