# Skill: Superhuman PM Velocity (Polish Layer)
Source: humanlayer/humanlayer (adapted for PM orchestration)

## Purpose
Enables keyboard-first UI, optimistic updates, and high-density layouts. Adheres strictly to the RaaS design spec.

## Core Instructions
1. **Zero-Latency Feedback**: Ensure all UI components provide immediate visual confirmation of actions.
2. **Optimistic Updates**: Update the UI state before the server/logic confirms, providing a "Superhuman" feel.
3. **High-Density Layouts**: Maximize information density while maintaining perfect spatial alignment and legibility.
4. **Keyboard-First**: Design all interactions to be accessible via keyboard shortcuts and high-velocity navigation.

## Visual Constraints
- Background: #0D0D0D (Zinc-950)
- Accent: #3B82F6 (Vibrant Blue)
- Typography: Plus Jakarta Sans / Outfit
- Iconography: Lucide-react (Thin line-art only)
