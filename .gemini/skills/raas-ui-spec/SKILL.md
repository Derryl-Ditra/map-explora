# Skill: RaaS UI Spec (Design System)
Source: Antigravity RaaS Master Instruction Set

## Purpose
Enforces the strictly minimalist, high-contrast visual identity of the Result as a Service (RaaS) paradigm. Ensures absolute consistency across all UI components.

## Core Design Tokens
- **Background**: #0D0D0D (Zinc-950). Avoid pure black.
- **Typography**: Pure White (#FFFFFF) or High-Contrast Light Gray (#F3F4F6).
- **Primary Font**: Plus Jakarta Sans / Outfit / Google Sans (Geometric Sans-Serif). NO INTER.
- **Accent Color**: #3B82F6 (Vibrant Blue). Used for CTAs and active states only.
- **Borders**: Ultra-thin 1px (Zinc-800/700).
- **Iconography**: Lucide-react (Thin line-art only). No filled or multi-color icons.

## Layout Principles
- **Generous Whitespace**: Maintain high legibility and premium feel.
- **High Information Density**: Optimize for expert users without visual clutter.
- **Glassmorphism**: Use backdrop-blur for HUD overlays.
