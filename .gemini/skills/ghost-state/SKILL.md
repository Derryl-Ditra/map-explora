# Skill: "Ghost" State Optimizer (Vibe Layer)
Source: cult-ui/interaction-skill

## Purpose
Adds high-fidelity hover states, skeleton loaders, and "optimistic" feedback. Ensures the interface feels alive and responsive, moving beyond an "AI demo" to a "Premium SaaS."

## Core Instructions
1. **High-Fidelity Hover**: Every interactive element must have a subtle, premium hover state (e.g., elevation change, glow, or backdrop-blur shift).
2. **Skeleton Loaders**: Use high-contrast skeleton states to mask data loading and prevent layout shifts.
3. **Optimistic Feedback**: Provide immediate visual confirmation for all actions (e.g., button press states, focus rings).
4. **Living Interface**: Implement micro-animations that respond to user movement and interaction.

## Logic Rules
- Reject static or "dead" components that lack feedback.
- Use the RaaS Blue accent for active and focused interactive states.
