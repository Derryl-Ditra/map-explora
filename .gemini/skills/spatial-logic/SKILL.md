# Skill: Spatial-Logic Architect (Design System)
Source: emilkowalski/spatial-mcp

## Purpose
Focuses on whitespace, alignment, and "The Rule of 8" (8px grid systems). Prevents cluttered layouts and ensures a minimalist, high-end density.

## Core Instructions
1. **Rule of 8**: Enforce a strict 8px geometric scale for all margins, paddings, and layout dimensions.
2. **Negative Space Prioritization**: If a layout feels crowded, remove 20% of the non-essential elements before finalization.
3. **Geometric Alignment**: Ensure all elements are perfectly aligned along the grid system to create a sense of order and precision.
4. **Minimalist Density**: Optimize information density without sacrificing legibility or whitespace.

## Logic Rules
- Reject any layout with ad-hoc or irregular spacing.
- Maintain a consistent spatial rhythm across all components and pages.
