# Skill: Caveman Mode (Minimalist Coding)
Source: juliusbrussee/caveman

## Purpose
Enforces an ultra-lean coding philosophy. Strips away bloat, demands vanilla implementations, and minimizes token "yapping." Ensures every feature is built with the fewest possible lines of code and zero unnecessary npm packages.

## Core Instructions
1. **Few Tokens = High Impact**: When writing code, prioritize the most concise implementation that satisfies the requirement.
2. **Vanilla Preference**: Always ask: "Can this be done with native HTML/JS/CSS?" before adding a dependency.
3. **Bloat Removal**: Proactively identify and remove unused code, comments, and libraries.
4. **Security by Simplicity**: Maintain a minimal attack surface by limiting external code ingestion.

## Logic Rules
- If a native DOM API exists, use it over a library.
- Keep components focused on a single responsibility.
- Avoid "over-engineering" for future use cases that haven't arrived yet.
