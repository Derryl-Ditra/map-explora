# Comparison v3 - draft implementation

Owner approved the place-first v3 flow and an aggregate-only open count on 19 November 2026. Draft only. No deployment or merge approval for this code.

## Flow

- One Compare action on the opened map sheet. Map, Directions/Search Maps and Share are unchanged. No card controls, tray or third selection.
- The map, sheet, filters and list remain mounted under an inert comparison overlay. Back restores that live surface; browser Back does the same. Replacement and cancellation do not navigate away.
- Picker retains the other branch and excludes it from results. Selects have equal weight. With one retained branch all public candidates are searchable; with zero selections there are no seeded choices.
- Replacement changes only its chosen side. Cancel retains both IDs and comparison scroll. Remove right keeps left; Remove first in its replacement picker promotes right. Removing the last leaves search only.
- Direct URLs and refresh have no live origin to restore. Back uses the default map, or the single selected place sheet. It never claims a prior pan or filter state.
- EN/ID switching is local to the overlay and preserves IDs/scroll/map state. Existing map UI remains its current bilingual/English presentation.
- Age/Fee/Review disclosures start closed, expand both columns together and use persistent identities. Location uncertainty, source conflicts and specialist education focus remain visible.

## Counter: deliberately disabled

`recordCompareOpen()` prepares only a constant aggregate event. It sends no network requests and writes no storage. It does not yet count opens in production.

The current GoatCounter script adds `location.search` to every event, and the service normally derives approximate location from IP and creates an in-memory session mapping. Therefore normal SDK events would not meet the approved no-IDs/no-location scope. `no_session` does not by itself disable location or the query field. No analytics-account setting was changed and no additional endpoint created.

Remaining gate: a verified aggregate-only sink, its retention and any necessary account changes need review before enabling. No silent fallback to current GoatCounter events.
