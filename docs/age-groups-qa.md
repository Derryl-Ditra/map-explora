# Under-5 age groups

User-selected bands: 0-12, 13-24, 25-36, 37-48, 49-59 months plus Any. No slider or exact-month presets. Rockstar's official https://www.rockstaracademy.com/programs uses broad 0-3, 4-6, 7-9, 10-12, 13+ year tabs. We verified that reference but followed the user's more useful monthly bands, not a claim that Rockstar uses these same bands.

A confirmed branch age claim overlapping any month in the selected group matches. It does not mean every age in the group is eligible. The UI says range overlap, and keeps unconfirmed places separately labeled. Brand policy, missing bounds, unconfirmed sources and ambiguous boundaries retain the existing exact-month honesty rules. Ages 60+ never match the final group.

17 tests including complete nonoverlapping 0-59 coverage, range overlap, brand/unknown rejection and 59/60 boundaries passed. TypeScript, export build and 390px no-slider selection checked. Draft PR only; no merge/deploy.
